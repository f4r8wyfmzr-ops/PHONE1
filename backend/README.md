# PHONE PAY Secure PSP Backend

Node.js + TypeScript gateway connecting the PHONE PAY Android app to an RBI-regulated Payment Service Provider (PSP) / Sponsor Bank.

## Quick Start
1. `cp .env.example .env`
2. Fill in `PSP_MERCHANT_ID`, `PSP_API_KEY`, `PSP_API_SECRET`, and `PSP_WEBHOOK_SECRET`.
3. `npm install && npm run build && npm start`

See `/docs/API_INTEGRATION.md` and `/docs/BUILD_AND_DEPLOYMENT.md` for full integration and deployment instructions.
